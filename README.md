# Prácticas de Python y Fundamentos de Ciencia de Datos

## Descripción del repositorio

Colección de ejercicios y prácticas académicas desarrolladas con Python y Jupyter Notebook para fortalecer los fundamentos de programación, el análisis computacional y la resolución de problemas.

El repositorio reúne actividades introductorias que complementan los proyectos de análisis de datos, Machine Learning e Inteligencia Artificial.

## Objetivos

- Fortalecer las bases de programación con Python.
- Practicar la implementación de soluciones computacionales.
- Desarrollar habilidades de análisis y resolución de problemas.
- Familiarizarse con el entorno de Jupyter Notebook.
- Organizar ejercicios de formación como evidencia del aprendizaje técnico.

## Contenido

### Caras

**Archivo:** `Caras.ipynb`

Práctica académica cuyo propósito específico debe documentarse de acuerdo con el código y las operaciones presentes en el notebook.

### Primeros pasos

**Archivo:** `Taller4_PrimerosPasos.ipynb`

Ejercicio introductorio de programación. Permite conservar y consultar el trabajo realizado durante la formación en Python.

## Tecnologías

- Python
- Jupyter Notebook

Las bibliotecas adicionales dependen de cada ejercicio.

## Ejecución

1. Instala Python.
2. Instala Jupyter Notebook.
3. Instala las dependencias requeridas por el ejercicio.
4. Abre el notebook que deseas consultar.
5. Ejecuta las celdas en orden.

```bash
pip install jupyter
jupyter notebook
```

## Competencias desarrolladas

- Fundamentos de programación.
- Resolución de problemas.
- Experimentación con código.
- Uso de notebooks.
- Organización y documentación del trabajo técnico.
